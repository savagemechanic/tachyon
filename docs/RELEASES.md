# Releases

Tachyon follows Semantic Versioning. The first usable research release is `v0.1.0`; this supersedes the originally proposed `v0.01` label by explicit user direction. Minor `0.x` releases may change unstable research interfaces, while patch releases contain compatible corrections. Tagged builds produce macOS Apple Silicon, macOS Intel, and Linux x86_64 archives plus SHA-256 checksums.
